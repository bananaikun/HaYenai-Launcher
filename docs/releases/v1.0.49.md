## 内容

一次性把两批工作合并发布：

1. **磁悬条生态适配**（主人点名的「还不是信息栏」）
   - 服务器卡从「fetch 一个 JSON 地址」改成真正走 Minecraft 协议：
     MOTD、服务器图标、真实在线人数、延迟；`playersUrl` 那套自己找接口的做法退场
   - 支持最多 4 台服务器，设置页增删改，卡片每台一行
   - 磁悬条新增「服务器」页（默认关闭）
   - 窄窗口（≤760px）条子贴边铺开、页点与控件收紧，服务器块缩短，不再横向溢出
2. **全仓代码审计与修复**（158 条 findings，按 §6 顺序落地 7 批）
   - 安全：登录镜像显式勾选（默认官方、不静默回落第三方）、拖入文件白名单 + 64MB、
     另存为限域、房间删除校验、服务端安装期禁止写
   - 数据：编辑实例丢更新、数据库迁移/频道切换的 WAL 顺序、安装恢复误回滚、
     双开游戏进程、库 jar 与版本 JSON 的损坏自愈
   - 生命周期：退出停止托管服务端 JVM、terracotta 停止确认、删除与启动互斥
   - 更新：Linux 走 GitHub Release 的 deb + sha256；明文探针只判活
   - 性能：系统资源采样移出主线程、月历 Intl 每秒 42 次、多轮询随可见性暂停、
     浏览页切源双搜、实例缓存整份写盘
   - 前端卡死/泄漏：拖入锁、不兼容弹窗回调、崩溃分享按钮、多处 listener 与定时器
3. **官网**：语言推断（en-GB/en-AU 不再判成中文）、下载按钮水合、下载服务降级、
   公告重复 id、国家列表硬编码
