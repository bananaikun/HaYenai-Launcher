**未在真机交互验证（需人工点一遍）**：

- 切换壁纸 → 首次显示 1.2s 后是否落静帧、下次切换是否先垫静帧。

- 备份/还原进行中启动实例 → 是否 20 秒内给出「实例正忙」提示而不是无限转圈。
