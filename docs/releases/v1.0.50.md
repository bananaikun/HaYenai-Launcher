## 这一版解决的五件事

1. **壁纸切换要等加载**——场景壁纸首次渲染成功后存一张静帧（`wallpapers/posters/<id>-frame.png`，最长边 1600，PNG），下次切换到它时先垫静帧再等引擎就绪，淡入不闪。静帧生成失败无副作用，缺了就回落 `preview`。
2. **启动实例失败会卡住**——维护锁加 20s 超时并给出「实例正忙」提示；Java 探测加 10s 超时并提示换 Java；启动超时但进程已登记时按「已启动」返回，消除「前端说失败、后端说在跑」的僵局；实例页出错时先复位按钮再弹崩溃分析。
3. **启动实例过慢**——库 jar 加 `<jar>.verified` 校验戳（size + mtime + sha1），没动过就跳过整份 SHA-1；显式 Java 路径不再探测两次。
4. **停止实例停不掉**——Windows 上改杀整个进程树（`taskkill /T /F`），JVM 被 `cmd /c`、shim 或 `.bat` 包着时不再残留后台进程。
5. **磁悬条没有临时信息**——启动 / 安装 / 下载进行中时条子整条切成进度视图（名称 + 阶段文案 + 进度条 + 百分比，安装与下载可取消），结束自动回原页、轮播位置不跳。阶段文案来自后端新增的 `launch_stage` 事件，不是秒表推断。
