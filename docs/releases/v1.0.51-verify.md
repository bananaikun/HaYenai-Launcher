**关于「exe 里 grep 不到文案」**：Tauri 对嵌入资源做压缩，二进制里只有资源**键名**（如 `Index-BUCCENKx.js`）是明文，内容里的字符串 grep 不到——所以 `findstr app.magnetic.stage-preparing target\release\HaYenai.exe` 返回 MISSING 不代表缺失。用「dist 里命中 + 该 js 资产键名在 exe 里存在」两条一起判断。
