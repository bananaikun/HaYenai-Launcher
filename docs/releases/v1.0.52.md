## 为什么

启动器每重启一次，第一次启动游戏都要为每个候选 GC 参数块真起一次 `java -version`（每次最多等 5 秒）。这是纯重复劳动——同一个 JDK、同一套参数，结果不会变。

## 怎么保证不误判

- 键含 Java 路径 + 文件大小 + mtime + 参数列表 → 换 JDK 自动失效。
- 只缓存 `supported = true` → 超时/spawn 失败这种瞬时结果不会被记成「这个参数不能用」。
- 超过 256 条整体清空 → 不写淘汰算法，也不会无限增长。
- 文件损坏 → `serde_json::from_str(...).unwrap_or_default()` 静默重建。

## 回滚

安装 1.0.51 即可（`release/1.0.51/`）。缓存文件在 `caches/jvm-probe-cache.json`，删掉只会让下次启动多等几秒，不损坏任何实例数据。
