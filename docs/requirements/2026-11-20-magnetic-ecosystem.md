# 磁悬条：信息源做真 + 环境自适应

- 日期：2026-11-20
- 决策：主人 Q1=B（只做第 1、2 包）/ Q2=B（服务器卡支持最多 4 个）/ Q3=A（开发模式验收，不打包）

## 目标

1. **信息源做真**：服务器卡不再只是"一个 HTTP 探活"，改吃 MC 协议（Rust `server_status` 已支持 SLP）：
   MOTD、服务器图标、真实在线/上限、延迟；HTTP 地址继续支持（2xx 才算在线）。
   一台条子支持 **最多 4 个服务器**，每台一行。
2. **条子能看**：条子新增「服务器」页（**默认关闭**），一屏看到所有服的在线人数与状态点。
3. **环境自适应**：
   - 窄窗（分屏 / 小屏）下条子本体单行收缩，不出横向溢出；
   - 浅色主题 / 浅壁纸下关键文字对比度实测并修正。

## 非目标

- 不做组件注册表与外部推送通道（第 3 包）。
- 不做按路由自动切换条子内容（第 4 包）。
- 不改 Rust 的 SLP 实现（MOTD/favicon 已够用），也不处理 SRV 解析。
- 不引入新依赖。

## 完成判据

- [ ] 设置页可增删服务器（名称 + 地址），上限 4，刷新后保持。
- [ ] 旧配置（单 `server` 对象）升级不丢地址，自动迁移成 1 条。
- [ ] 面板服务器卡每行显示：状态点、名称、MOTD（有则显示）、在线/上限、延迟（开关打开时）、图标（有则显示）。
- [ ] 条子服务器页显示每服状态与人数，默认关闭、可在设置里打开。
- [ ] 1024×600 与 1280×720 窗口下条子无横向溢出（实测，非目测）。
- [ ] 浅色主题 + 浅壁纸下条子正文与面板卡标题对比度 ≥ 4.5:1（实测记录数值）。
- [ ] `pnpm --filter @modrinth/app-frontend fix` 与 lint/typecheck 通过；开发模式实测截图。
